# นัดวันไปเที่ยว 🧳

เว็บให้เพื่อนเข้ามาเลือกวันที่ว่าง → เก็บลง Google Sheet → เว็บสรุปให้ว่าวันไหนว่างตรงกันมากที่สุด

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บ (ปฏิทินเลือกวัน + สรุปผล) |
| `Code.gs` | โค้ดหลังบ้านที่อยู่ใน Google Sheet (รับข้อมูล/ส่งข้อมูล) |

> ถ้ายังไม่ได้ตั้งค่า `SCRIPT_URL` เว็บจะทำงานใน **โหมดทดลอง** (เก็บข้อมูลไว้ในเบราว์เซอร์ตัวเองเท่านั้น)

## ขั้นที่ 1 — สร้าง Google Sheet + Apps Script

1. เข้า <https://sheets.new> สร้างชีตใหม่ ตั้งชื่อเช่น `นัดเที่ยว`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางโค้ดทั้งหมดจากไฟล์ `Code.gs` → กด 💾 บันทึก
4. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - กดรูปเฟือง ⚙ → เลือก **เว็บแอป (Web app)**
   - **ดำเนินการในฐานะ (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)**
   - กด Deploy → กด **ให้สิทธิ์เข้าถึง** → เลือกบัญชีตัวเอง
     (ถ้าขึ้น "Google hasn't verified this app" ให้กด *Advanced → Go to ... (unsafe)* — เป็นสคริปต์ของเราเอง)
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

## ขั้นที่ 2 — ใส่ URL ในหน้าเว็บ

เปิด `index.html` หาบรรทัดนี้ แล้ววาง URL ลงไป:

```js
const SCRIPT_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

เปิดหน้าเว็บ ลองส่งดู 1 ครั้ง → ในชีตจะมีแท็บ `Responses` โผล่ขึ้นมาพร้อมข้อมูล

## ขั้นที่ 3 — เอาขึ้นเว็บให้เพื่อนเข้า (GitHub Pages)

1. สร้าง repo ใหม่บน GitHub เช่น `trip-date-poll` (Public)
2. อัปโหลด `index.html` ขึ้นไป
3. **Settings → Pages → Branch: `main` / root → Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://<username>.github.io/trip-date-poll/` → ส่งให้เพื่อนได้เลย

## หมายเหตุ

- ถ้าแก้ `Code.gs` ภายหลัง ต้อง **Deploy → Manage deployments → ✏️ → Version: New version** ไม่งั้น URL เดิมจะยังใช้โค้ดเก่า
- เพื่อนกรอกชื่อเดิมแล้วส่งใหม่ = **แก้ไข** วันที่ของตัวเอง (ไม่ซ้ำ)
- ใครมีลิงก์ก็เข้ามากรอก/เห็นชื่อคนอื่นได้ ไม่มีระบบล็อกอิน — เหมาะกับใช้ในกลุ่มเพื่อน
- ข้อมูลในชีต: 1 แถว = 1 คน × 1 วัน (`Timestamp | Name | Date | Note`)
