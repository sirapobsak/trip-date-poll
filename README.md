# นัดวันไปเที่ยว 🧳

เว็บ: <https://sirapobsak.github.io/trip-date-poll/>

เพื่อนเลือกชื่อตัวเอง → จิ้มวันที่ว่าง → ระบบใส่ ✓ ลงตารางใน Google Sheet → เว็บสรุปให้ว่าวันไหนว่างตรงกันมากที่สุด

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บ (เลือกชื่อ + ปฏิทิน + สรุปผล) |
| `Code.gs` | โค้ด Apps Script ที่อยู่ใน Google Sheet |

## รูปแบบในชีต

ใช้ชีตต้นแบบ (ชีตที่ช่อง A4 เขียนว่า `ชื่อ` และรายชื่ออยู่คอลัมน์ A ตั้งแต่แถว 5)
สคริปต์จะก๊อปเป็น **1 แท็บต่อเดือน** ตั้งแต่ **ธันวาคม 2569 ถึง พฤษภาคม 2570**:

- แถว 2 = `เดือน <เดือน> <ปี>` · แถว 3 = วันที่ 1–28/29/30/31 ตามจริงของเดือนนั้น · แถว 4 = วันในสัปดาห์
- ช่องที่ว่าง = `✓` (พื้นเขียว)
- อยากเปลี่ยนช่วงเดือน → แก้ `START` / `END` ใน `Code.gs` และ `RANGE_START` / `RANGE_END` ใน `index.html`
- อยากเพิ่ม/แก้ชื่อ → แก้ในชีตต้นแบบ **ก่อน** สร้างแท็บเดือน (หรือแก้ให้ตรงกันทุกแท็บ)

## ตั้งค่า (ทำครั้งเดียว)

1. เปิด Google Sheet → **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางโค้ดทั้งหมดจาก `Code.gs` → 💾 บันทึก
3. (แนะนำ) เลือกฟังก์ชัน `setupSheets` ด้านบน → กด **▶ เรียกใช้ (Run)** → อนุญาตสิทธิ์
   → จะได้แท็บ ธันวาคม 2569 … พฤษภาคม 2570 (ถ้าข้ามขั้นนี้ เว็บจะสร้างให้เองตอนเปิดครั้งแรก)
4. **Deploy → New deployment** → ⚙ **Web app**
   - Execute as: **Me** · Who has access: **Anyone** → Deploy
   - ถ้าขึ้น "Google hasn't verified this app" → *Advanced → Go to ... (unsafe)*
5. คัดลอก **Web app URL** (ลงท้าย `/exec`) → ใส่ใน `index.html` ที่ `const SCRIPT_URL = "...";`

## หมายเหตุ

- แก้ `Code.gs` ภายหลัง ต้อง **Deploy → Manage deployments → ✏️ → Version: New version**
- เลือกชื่อเดิมแล้วส่งใหม่ = เขียนทับวันที่ของคนนั้นทั้งหมด
- ไม่มีระบบล็อกอิน ใครมีลิงก์ก็เลือกชื่อใครก็ได้ — เหมาะกับใช้ในกลุ่มเพื่อน
